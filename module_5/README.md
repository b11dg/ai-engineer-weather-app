# Модуль 5. Контент-конвейер на LangChain (LCEL)

> Это задание модуля 5. Обзор всех модулей есть в [корневом README](../README.md).

Два маленьких ланцюжка LangChain склеены в один конвейер через LCEL (LangChain Expression Language). Первый по теме придумывает заголовок статьи, второй по этому заголовку пишет абзац-вступ. Заголовок сам передаётся из первого ланцюжка во второй, вручную ничего не копируется.

- **API:** [OpenRouter](https://openrouter.ai) через `langchain-openai` (`ChatOpenAI` с `base_url` OpenRouter)
- **Модель:** NVIDIA Nemotron 3.5 Super VL, бесплатная версия (`nvidia/nemotron-3.5-super-vl:free`)
- **Библиотеки:** `langchain-core` (промпты, парсер, `RunnablePassthrough`) и `langchain-openai` (модель)
- **Файл:** [`content_pipeline.py`](content_pipeline.py)

## Почему эта модель

Сначала пробовал Nemotron 3.5 Lightning из модуля 1: она быстрее, но по-украински пишет с опечатками и начинает предложения с маленькой буквы. Super VL (как в модулях 3–4) пишет чистый украинский текст. Весь конвейер с двумя запросами занимает около 15–20 секунд.

## Как устроен конвейер

```
{"topic": "..."}
      │
      ▼
 chain1 = prompt1 | model | StrOutputParser()       → заголовок (строка)
      │
      ▼  RunnablePassthrough.assign(title=chain1)
{"topic": "...", "title": "..."}
      │
      ▼
 chain2 = prompt2 | model | StrOutputParser()       → вступ (строка)
      │
      ▼  RunnablePassthrough.assign(intro=chain2)
{"topic": "...", "title": "...", "intro": "..."}
```

**Ланцюжок 1 (генератор идей).** `ChatPromptTemplate` с переменной `{topic}` просит один яркий заголовок, без кавычек и пояснений. `StrOutputParser()` достаёт из ответа модели (`AIMessage`) просто строку.

**Ланцюжок 2 (писатель).** Другой `ChatPromptTemplate` с переменной `{title}` просит короткий абзац-вступ на 3–5 предложений.

**Склейка.** Ланцюжок 2 ждёт на вход словарь с ключом `title`, а ланцюжок 1 возвращает строку. Нужно переложить строку в словарь, и это делает `RunnablePassthrough.assign()`:

```python
overall_chain = (
    RunnablePassthrough.assign(title=chain1)
    | RunnablePassthrough.assign(intro=chain2)
)
```

`assign(title=chain1)` пропускает входной словарь дальше без изменений и добавляет в него ключ `title` с результатом `chain1`. Следующий `assign` так же добавляет `intro`. В итоге на выходе есть и тема, и заголовок, и вступ, поэтому в терминал можно вывести статью целиком.

Короче можно было бы так:

```python
overall_chain = {"title": chain1} | chain2
```

Словарь в LCEL сам превращается в `RunnableParallel`. Он запускает `chain1` и кладёт результат под ключ `title`. Но тогда на выходе только текст вступа, а заголовок теряется.

## Запуск

Команды выполняются из корня проекта, окружение общее.

```bash
# 1. Виртуальное окружение и зависимости (если ещё не сделано)
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 2. Ключ OpenRouter в корневом .env
cp .env.example .env
# впишите ключ в MODEL_API_KEY=...

# 3. Запуск
python module_5/content_pipeline.py
```

## Пример (реальный запуск)

```
Тема: Майбутнє космічного туризму

Білети на орбиту: космічний туризм стає реальністю

Щодавня мрія людяності про подорожі між зірками сьогодні поступово стає реальністю. Приватні компанії вже продають білети на суборбітальні та орбітальні польоти, а перші космічні туристи повертаються на Землю з неповторними враженнями. Хоча ціни на такі пригоди ще кусаються, технічний прогрес і збільшення конкуренції поступово роблять космос ближчим до звичайних людей. У цій статті розберемо, як працює космічний туризм сьогодні і що чекати нам у найближчому майбутньому.
```

`temperature=0.8`, поэтому при каждом запуске заголовок и текст разные.
