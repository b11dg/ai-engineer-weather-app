# Модуль 2. Арена температур

> Это задание модуля 2. Погодный ассистент в корне репозитория ([`weather.py`](../weather.py)) относится к модулю 1. Обзор всех модулей есть в [корневом README](../README.md).

Скрипт отправляет один и тот же промпт одной и той же модели дважды: с `temperature = 0.0` и с `temperature = 1.0`. Два ответа печатаются друг под другом, чтобы было видно, как температура влияет на результат.

- **API:** [OpenRouter](https://openrouter.ai)
- **Модель:** NVIDIA Nemotron 3 Ultra (`nvidia/nemotron-3-ultra-550b-a55b`)
- **Файл:** [`arena.py`](arena.py)

## Что такое температура

Температура управляет тем, как модель выбирает следующий токен:

- **0.0**: почти всегда берётся самый вероятный токен. Ответ получается предсказуемым и аккуратным.
- **1.0**: токены выбираются случайно с учётом их вероятностей. Ответ разнообразнее, но иногда в него попадают маловероятные, «странные» токены.

## Промпт

Задание специально смешанное: в нём есть творческая часть, на которую температура влияет сильно, и жёсткий формат, по которому два ответа легко сравнить.

> Придумай кофейню, которая находится прямо внутри IT-офиса.
> Дай ответ строго в таком формате:
> 1. Название (одно)
> 2. Слоган (одна фраза)
> 3. Описание атмосферы (3-4 предложения)
> 4. Три необычных напитка для меню: название и одно предложение, почему он понравится программистам.

## Запуск

Окружение общее для всего репозитория, поэтому команды выполняются из корня проекта.

```bash
# 1. Виртуальное окружение и зависимости (если ещё не сделано)
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 2. Ключ OpenRouter в корневом .env
cp .env.example .env
# впишите ключ в MODEL_API_KEY=...

# 3. Запуск
python module_2/arena.py
```

Скрипт сам находит `.env` в корне репозитория, поэтому его можно запускать из любой папки.

> Nemotron 3 Ultra сначала рассуждает, а потом отвечает, поэтому один запрос может идти до минуты. Таймаут в скрипте 180 секунд. `max_tokens` поднят до 3000, потому что токены рассуждения тоже расходуют этот лимит.

## Настройка

Всё, что можно менять, вынесено в константы в начале [`arena.py`](arena.py):

| Константа      | По умолчанию                          | Что задаёт                       |
|----------------|---------------------------------------|----------------------------------|
| `MODEL`        | `nvidia/nemotron-3-ultra-550b-a55b`   | Любая модель с OpenRouter        |
| `TEMPERATURES` | `[0.0, 1.0]`                          | Список температур для сравнения  |
| `PROMPT`       | кофейня в IT-офисе                    | Промпт, одинаковый для всех прогонов |

## Пример вывода

Model: nvidia/nemotron-3-ultra-550b-a55b

## Наблюдения

Скрипт запускался два раза. Полные заметки лежат в конце [`arena.py`](arena.py).

| | `temperature = 0.0` | `temperature = 1.0` |
|---|---|---|
| **Язык** | Чистый русский, без ошибок | Смесь языков и опечатки: «рестриretto», «кoldt brew», даже корейское «맛» посреди фразы |
| **Формат** | Соблюдён точно, 3-4 предложения в описании | Структура 1-2-3-4 сохранена, но описание выходит за 3-4 предложения |
| **Идеи** | Самые ожидаемые: Runtime, Garbage Collector, Hot Reload, Legacy Latte | Ядро то же, но больше деталей и шуток («латте для смелости деплоить в пятницу») |
| **Повторяемость** | Ответ между запусками всё равно менялся («Runtime» → «Root Access») | Ответы разные, как и ожидалось |

### Почему `temperature = 0` не дал одинаковых ответов

- OpenRouter может отправить запрос разным провайдерам модели.
- На GPU при пакетной обработке запросов возникает небольшой численный шум.
- Модель сначала рассуждает, и маленькое расхождение в рассуждении меняет весь ответ.

## Выводы

- **Низкая температура (0–0.3)** подходит там, где важны точность и следование инструкции: факты, код, извлечение данных, JSON.
- **Высокая температура (~1.0)** даёт разнообразие и неожиданные детали, но ответ нужно проверять: качество текста падает. Для креативных задач разумный компромисс где-то **0.6–0.8**.
- **Температура 0 не гарантирует воспроизводимость.** Если она нужна, задайте `seed` и зафиксируйте провайдера.
