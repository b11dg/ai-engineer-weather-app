# Модуль 6. Граф модерації коментарів (LangGraph)

> Это задание модуля 6. Обзор всех модулей есть в [корневом README](../README.md).

Граф на LangGraph читает комментарий к статье в блоге и направляет его нужному «специалисту». Сначала узел-анализатор просит модель вернуть одно слово: `TOXIC`, `QUESTION` или `NORMAL`. Затем условное ребро по этому слову выбирает ветку: токсичный комментарий удаляется с фиксированным ответом, на вопрос отвечает модель, а обычный отзыв уходит сразу в `END`, без ответа.

- **API:** [OpenRouter](https://openrouter.ai) через `langchain-openai` (`ChatOpenAI` с `base_url` OpenRouter)
- **Модель:** NVIDIA Nemotron 3.5 Super VL, бесплатная версия (`nvidia/nemotron-3.5-super-vl:free`)
- **Библиотеки:** `langgraph` (граф и состояние), `langchain-core` (промпты и парсер), `langchain-openai` (модель)
- **Файл:** [`moderator_graph.py`](moderator_graph.py)

## Как устроен граф

```
                  ┌──────────────────┐
START ──────────► │  analyze_comment │
                  └────────┬─────────┘
                           │ route_by_category(state)
              ┌────────────┼────────────────┐
        TOXIC │      QUESTION              │ NORMAL
              ▼            ▼                ▼
     ┌────────────────┐ ┌────────────┐    END
     │ toxic_handler  │ │ qa_handler │
     └───────┬────────┘ └──────┬─────┘
             ▼                 ▼
            END               END
```

## Состояние

`AgentState` — это `TypedDict` с тремя полями из задания:

```python
class AgentState(TypedDict):
    comment: str
    category: str
    final_response: str
```

В граф передаётся комментарий, а также пустые `category` и `final_response`: так в финальном состоянии каждого запуска есть все три поля, даже когда ответ не нужен.

## Узлы

**`analyze_comment` (анализатор).** Отправляет комментарий в модель с промптом, который просит ровно одно слово: `TOXIC` (оскорбления), `QUESTION` (вопрос по теме) или `NORMAL` (обычный отзыв). Ответ переводится в верхний регистр и записывается в `state["category"]`. Если модель добавила вокруг слова знаки препинания или короткое пояснение, категория ищется внутри ответа; если ничего не найдено, выбрасывается `ValueError`, а не молчаливая ошибка маршрутизации.

```python
answer = analyzer_chain.invoke({"comment": state["comment"]})
category = answer.strip().upper()
...
return {"category": category}
```

Для анализатора `temperature=0`: классификация должна быть одинаковой при каждом запуске.

**`toxic_handler`.** Ничего не спрашивает у модели, просто записывает фиксированный ответ:

```python
TOXIC_RESPONSE = "Ваш коментар видалено через порушення правил."
```

**`qa_handler`.** Просит модель вежливо ответить на вопрос читателя на том же языке, коротко (2–4 предложения), без приветствия, подписи и Markdown. Ответ записывается в `final_response`. Здесь `temperature=0.7`, чтобы формулировки не были одинаковыми.

## Условное ребро

`route_by_category()` — обычная функция, которая смотрит на `state["category"]` и возвращает имя следующего узла или `END`:

```python
def route_by_category(state: AgentState) -> str:
    if state["category"] == "TOXIC":
        return "toxic_handler"
    if state["category"] == "QUESTION":
        return "qa_handler"
    return END
```

В `add_conditional_edges()` эта функция связана с узлами графа. Для `NORMAL` она возвращает `END`, поэтому обычный отзыв проходит только через анализатор и завершает граф.

## Запуск

Команды выполняются из корня проекта, окружение общее.

```bash
# 1. Виртуальное окружение и зависимости (если ещё не сделано)
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 2. Ключ OpenRouter в корневом .env
cp .env.example .env
# впишите ключ в MODEL_API_KEY=...

# 3. Запуск
python module_6/moderator_graph.py
```

Скрипт трижды вызывает `graph.invoke()` с комментариями из задания и печатает финальное состояние каждого запуска.

## Пример (реальный запуск)

```
=== Запуск 1 ===
Коментар:  Ця стаття повний відстій, автор дурень!
Категорія: TOXIC
Відповідь: Ваш коментар видалено через порушення правил.

=== Запуск 2 ===
Коментар:  А як встановити цю бібліотеку на Windows?
Категорія: QUESTION
Відповідь: Ви можете встановити бібліотеку через командний рядок. Відкрийте Термінал або Командний рядок і введіть команду pip install назва_бібліотеки. Якщо виникнуть труднощі, перевірте, чи додано Python до шляху PATH, або зверніться до документації бібліотеки.

=== Запуск 3 ===
Коментар:  Дякую, дуже цікаво!
Категорія: NORMAL
Відповідь: — (відповідь не потрібна)
```

Запуск занимает около 5–15 секунд: одно обращение к модели для анализа каждого комментария и ещё одно для ответа на вопрос.
